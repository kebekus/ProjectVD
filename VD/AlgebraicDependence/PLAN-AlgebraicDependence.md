# Plan: Algebraic Dependence and the Valiron–Mohon'ko Theorem

Working plan for formalizing the growth of meromorphic functions that are *algebraic over a
field of meromorphic functions*, together with its sharpening, the **Valiron–Mohon'ko
identity** `T(r, R(f)) = deg R · T(r, f) + S(r, f)` for rational functions `R` with small
coefficients, and the two companion estimates in Laine's Chapter 2, **Clunie's lemma** and
**Mohon'ko's lemma** (in their algebraic, derivative-free form). Prepared 2026-10-06 against the
Mathlib checkout in `.lake` (commit `7d6757bc1868…`, toolchain v4.35.0-rc3). Companion to
`VD/SMT/PLAN-SecondMainTheorem.md` and `VD/LLD/PLAN-LogarithmicDerivative.md`; builds on the
field of meromorphic germs in `VD/Field/`.

References:

- Laine, *Nevanlinna Theory and Complex Differential Equations*, de Gruyter Studies in
  Mathematics 15 (1993), §2.2 (Theorem 2.2.5 = Valiron–Mohon'ko) and §2.4 (Clunie, Mohon'ko);
- Valiron, *Sur la dérivée des fonctions algébroïdes*, Bull. Soc. Math. France 59 (1931);
- Mohon'ko, *The Nevanlinna characteristics of certain meromorphic functions*, Teor. Funktsiĭ
  Funktsional. Anal. i Prilozhen. 14 (1971), 83–87;
- Eremenko, *Meromorphic solutions of algebraic differential equations*, Russian Math. Surveys
  37 (1982), §6 (the "purely algebraic" proof and the two-variable generalization);
- Hayman, *Meromorphic Functions* [MR164038], §1.3 (elementary inequalities for `T`).

## 1. Goal

**Classical statements.** Throughout, `f`, `g`, `a₀, …` are meromorphic on `ℂ`, `T = T(r, ·)` is
the Nevanlinna characteristic `ValueDistribution.characteristic · ⊤`, and `1 ≤ r`.

```
(AD)  f^d + a_{d-1} f^{d-1} + … + a₀ = 0        ⟹  T(r, f) ≤ Σ_{j<d} T(r, aⱼ) + log d

(★)   f^d + a_{d-1} f^{d-1} + … + a₀ = g        ⟹  d·T(r, f) ≤ T(r, g) + d·Σ_{j<d} T(r, aⱼ) + d·log(2(d+1))

(VM)  P(w) = Σ_{j≤d} aⱼ wʲ, a_d ≢ 0              ⟹  |T(r, P(f)) − d·T(r, f)| ≤ C·Σ_{j≤d} T(r, aⱼ) + c

(VMr) R = P/Q, P, Q coprime over a field F of      ⟹  T(r, R(f)) = max(deg P, deg Q)·T(r, f) + S(r)
      "small" functions, with S(r) ∈ growth class of F

(Cl)  fⁿ·P(f) = Q(f), deg Q ≤ n                   ⟹  m(r, P(f)) ≤ Σ m(r, coeffs of P, Q) + O(1)

(Mo)  P(f) = 0, P(0) = a₀ ≢ 0                     ⟹  m(r, 1/f) ≤ m(r, 1/a₀) + Σ_{j≥1} m(r, aⱼ) + O(1)
```

(AD) is the "algebraic dependence" theorem: if `f` is algebraic over the field generated by
`f₁, …, fₙ`, then `T(r, f) = O(Σᵢ T(r, fᵢ)) + O(1)`. (★) is the weighted master inequality from
which (AD), the lower half of (VM) and (Mo)-type arguments all follow; its proof is the only
place where the factor `d` is won. (VMr) is Laine's Theorem 2.2.5 (Valiron 1931, Mohon'ko 1971).
(Cl) and (Mo) are Laine's Lemma 2.4.2 and the Mohon'ko lemma, restricted to ordinary (not
differential) polynomials; the differential versions are scoped out to §10.

**Formal targets.** Nine headline theorems, on two layers.

*Function level* (`f, aⱼ : ℂ → ℂ`, finite sums over `Finset.range`, no field structure):

```lean
-- (T1) The master inequality (★).
theorem ValueDistribution.nsmul_characteristic_le_of_monic_eq {f g : ℂ → ℂ} {a : ℕ → ℂ → ℂ}
    {d : ℕ} (hf : Meromorphic f) (hg : Meromorphic g) (ha : ∀ j, Meromorphic (a j))
    (h : f ^ d + ∑ j ∈ range d, a j * f ^ j =ᶠ[codiscrete ℂ] g) {r : ℝ} (hr : 1 ≤ r) :
    d * characteristic f ⊤ r
      ≤ characteristic g ⊤ r + d * ∑ j ∈ range d, characteristic (a j) ⊤ r
        + d * log (2 * (d + 1))

-- (T2) The algebraic dependence bound (AD).
theorem ValueDistribution.characteristic_le_sum_characteristic_of_monic_eq_zero {f : ℂ → ℂ}
    {a : ℕ → ℂ → ℂ} {d : ℕ} (hf : Meromorphic f) (ha : ∀ j, Meromorphic (a j))
    (h : f ^ d + ∑ j ∈ range d, a j * f ^ j =ᶠ[codiscrete ℂ] 0) {r : ℝ} (hr : 1 ≤ r) :
    characteristic f ⊤ r ≤ ∑ j ∈ range d, characteristic (a j) ⊤ r + log d

-- (T3) Polynomial Valiron–Mohon'ko (VM), two-sided, explicit constants.
theorem ValueDistribution.exists_abs_characteristic_polynomial_sub_le {f : ℂ → ℂ}
    {a : ℕ → ℂ → ℂ} {d : ℕ} (hf : Meromorphic f) (ha : ∀ j, Meromorphic (a j))
    (hd : ¬ a d =ᶠ[codiscrete ℂ] 0) :
    ∃ c, ∀ r, 1 ≤ r →
      |characteristic (∑ j ∈ range (d + 1), a j * f ^ j) ⊤ r - d * characteristic f ⊤ r|
        ≤ (d ^ 2 + 1) * ∑ j ∈ range (d + 1), characteristic (a j) ⊤ r + c
    -- (as implemented; the plan originally said `2 * d + 1`, see §6)

-- (T4) Clunie's lemma (Cl), algebraic case.
theorem ValueDistribution.proximity_le_of_pow_mul_eq {f : ℂ → ℂ} {a b : ℕ → ℂ → ℂ} {n p : ℕ}
    (hf : Meromorphic f) (ha : ∀ j, Meromorphic (a j)) (hb : ∀ k, Meromorphic (b k))
    (h : f ^ n * (∑ j ∈ range (p + 1), a j * f ^ j)
      =ᶠ[codiscrete ℂ] ∑ k ∈ range (n + 1), b k * f ^ k) {r : ℝ} (hr : r ≠ 0) :
    proximity (∑ j ∈ range (p + 1), a j * f ^ j) ⊤ r
      ≤ ∑ j ∈ range (p + 1), proximity (a j) ⊤ r + ∑ k ∈ range (n + 1), proximity (b k) ⊤ r
        + log (max (p + 1) (n + 1))

-- (T5) Mohon'ko's lemma (Mo), algebraic case.
theorem ValueDistribution.proximity_zero_le_of_eq_zero {f : ℂ → ℂ} {a : ℕ → ℂ → ℂ} {d : ℕ}
    (hf : Meromorphic f) (ha : ∀ j, Meromorphic (a j))
    (h : ∑ j ∈ range (d + 1), a j * f ^ j =ᶠ[codiscrete ℂ] 0) (h₀ : ¬ a 0 =ᶠ[codiscrete ℂ] 0)
    {r : ℝ} (hr : r ≠ 0) :
    proximity f 0 r ≤ proximity (a 0) 0 r + ∑ j ∈ Ico 1 (d + 1), proximity (a j) ⊤ r + log d
```

### Design decisions (and why)

1. **Two layers, function level first.** Packages A–E are stated for functions `ℂ → ℂ` with
   explicit coefficient families `a : ℕ → ℂ → ℂ` and sums over `Finset.range`. They are
   Mathlib-ready without the germ field and already give (AD), (VM), (Cl), (Mo) with explicit
   constants. Packages F–G add the germ-field layer, where the words "algebraic over", "field
   generated by", "coprime", "Euclidean division" and "Bezout" mean what they say. Only the
   sharp *rational* identity (T8) genuinely needs the field: its proof divides polynomials.

2. **No `Polynomial (ℂ → ℂ)` at the function level.** Coefficients as functions `a j`, monic
   normal form `f ^ d + ∑ j ∈ range d, a j * f ^ j`, pointwise evaluation by
   `simp [Finset.sum_apply, Pi.mul_apply, Pi.pow_apply]`. This sidesteps `natDegree`
   bookkeeping and the `Polynomial.eval`-over-`Pi`-ring bridge (`Polynomial.hom_eval₂` +
   `eval_map`), which would be needed on every pointwise estimate. `Polynomial` appears only at
   germ level (packages F–G), where `Polynomial.Monic.as_sum` and `Polynomial.eval_eq_sum_range`
   translate back to `range`-sums once.

3. **Identities only `=ᶠ[codiscrete ℂ]`, junk values never trusted.** All hypotheses are
   codiscrete equalities. Integration trick for (T1)/(T2)/(T3): the pointwise estimates of
   package A are applied to the *actual* function `h := f ^ d + ∑ …` (an identity, true
   everywhere), integrated with `circleAverage_mono`, and only then is `h` swapped for `g` via
   `characteristic_congr_codiscrete` (needs `r ≠ 0`). The same trick works at divisor level via
   `divisor_congr_codiscreteWithin`. (T4)/(T5) cannot use it (their pointwise estimates need the
   relation *at the point*) and integrate with `circleAverage_mono_codiscreteWithin`
   (`VD/LLD/LogDerivEstimates.lean`, public, Mathlib-bound).

4. **Non-asymptotic statements with explicit constants, for all `1 ≤ r`.** As in
   `characteristic_add_top_le`. Asymptotic corollaries (`=O`, `=o`, growth classes) are derived,
   never primary. The constants are not optimized (`log (2 * (d + 1))` in (★)); the sharp
   `log d` in (T2) is kept because it is free.

5. **"Small functions" as growth classes.** A structure `IsGrowthClass l G` (constants, sums,
   eventual domination, `l ≤ atTop`) with two instances, `(· =O[l] φ)` for `1 =O[l] φ` and
   `(· =o[l] φ)` for `Tendsto φ l atTop`. The classical `S(r, f)` is the little-o class along
   `volume.cofinite ⊓ atTop` with `φ = characteristic f ⊤`; the "bounded by `Σ T(r, fᵢ)`" class
   of (T7) is the big-O class along `atTop`. One definition of `growthField`, one proof of (T6),
   both classical statements as instances. Little-o is essential: with big-O the error term in
   (T8) would swallow the main term.

6. **Why the sharp rational case is harder, and how it is done.** Three natural routes were
   checked and *fail* to give the factor `max(p, q)`:
   - triangle-inequality induction along the Euclidean algorithm gives `(2q − p)·T(r, f)`;
   - applying (★)/(AD) to `P(f) − g·Q(f) = 0` (a monic relation over `K(g)`) gives
     `T(r, f) ≤ T(r, g) + S`, losing the factor `d` because `g` enters *every* coefficient;
   - a Cartan-type vector characteristic of the coefficient vector `A − g·B` gives the same
     unweighted bound.
   The route that works (Mohon'ko): WLOG `p ≥ q` (else invert); the **upper bound** by
   induction on `deg Q` through Euclidean division `P = S·Q + P₁`, inversion
   `T(r, P₁(f)/Q(f)) = T(r, Q(f)/P₁(f)) + O(1)` and the polynomial case; the **lower bound** by
   splitting `T(r, g) = m + N` and proving pointwise/divisor-wise
   `(p − q)·log⁺|f| + log⁺|1/Q(f)| ≤ log⁺|g| + small` resp.
   `(p − q)·(div f)⁻ + (div Q(f))⁺ ≤ (div g)⁻ + small`, where "small" is controlled through a
   **Bezout identity** `U·P + V·Q = 1` in `F[X]` (`IsCoprime`), whose coefficients lie in the
   growth field. Then `T(r, 1/Q(f)) = T(r, Q(f)) + O(1) = q·T(r, f) + S` finishes. Package G.

7. **Hypothesis-free product bound.** `characteristic_mul_top_le` requires
   `∀ z, meromorphicOrderAt fᵢ z ≠ ⊤` for both factors. For `ℂ → ℂ` and `1 ≤ r` these
   hypotheses are removable (`Meromorphic.exists_meromorphicOrderAt_eq_top_iff_eventually_zero`
   makes the degenerate factor codiscretely `0`, and then `T(r, f₁f₂) = T(r, 0) = 0`). Package
   C0 provides the primed version; it saves a case split at every use site in D–G and is a
   Mathlib improvement on its own.

8. **No vector (Cartan) characteristic.** Tempting for Valiron's algebroid theorem, but (see 6)
   it does not help with the sharp rational identity, and it is a separate project (holomorphic
   curves). Not introduced.

9. **Statement of (T7) via `IntermediateField.adjoin`.** The field generated by the `gᵢ` is
   `IntermediateField.adjoin ℂ (range (toGerm ∘ g))`, where `toGerm` is the coercion of a
   meromorphic function to `K` (`coe_mem_germRing`). Proof: `adjoin_le_iff` puts the generated
   field inside the big-O growth field for `φ = Σᵢ T(r, gᵢ) + 1`; `IsAlgebraic.tower_top` (or
   `tower_top_of_subalgebra_le`) lifts algebraicity; (T6) concludes. No induction over the
   adjoin construction is needed — the growth field *is* the induction.

10. **Differential polynomials are out of scope** (§10): the derivative-carrying versions of
    (Cl)/(Mo) need the LLD for `f⁽ᵏ⁾/f` and a definition of differential polynomials. Pointwise
    estimates of package A are written so that they apply verbatim to the differential case
    (the only change is the integration step).

## 3. Work package A — pointwise estimates ✅ **DONE** (2026-10-06, except G2)

*File `VD/AlgebraicDependence/PointwiseEstimates.lean`. Pure `NormedField` algebra, no
meromorphy, no integration. Mathlib target: `Mathlib/Analysis/SpecialFunctions/Log/PosLog.lean`
(or a new `PosLog/Polynomial.lean`). Independent of everything else.*

*Implementation notes.* All four lemmas below are proved with exactly the planned statements
and constants (~230 lines, builds warning-free). Two public helpers carry the norm estimates:
`Real.norm_sum_mul_pow_le_of_norm_le_one` (`‖w‖ ≤ 1 ⟹ ‖Σ aⱼ wʲ‖ ≤ Σ ‖aⱼ‖`) and
`Real.norm_sum_mul_pow_le_of_one_le_norm` (`1 ≤ ‖w‖ ⟹ ‖Σ_{j≤d} aⱼ wʲ‖ ≤ (Σ ‖aⱼ‖)·‖w‖^d`); every
case split in A reduces to one of them plus `posLog_sum`/`posLog_mul`. The degree-zero cases
are dispatched by `rcases d with _ | d` up front (the hypothesis is then `1 = 0`, or the
statement is `0 ≤ log⁺ ‖g‖`). The constant `log (1 + S) ≤ log (d + 2) + Σ log⁺ ‖aⱼ‖` is proved
through `Finset.exists_max_image` as sketched; `Real.log_one_add_le_posLog` would give the
weaker `d·log(4d)` and was not used. Lean trivia: `Σ` is a reserved token and cannot appear in
identifiers such as `hΣ₀`. The Bezout estimate G2 is deferred to package G, where its exact
shape is fixed.

```lean
namespace Real
variable {𝕜 : Type*} [NormedField 𝕜]

/-- **Weighted root bound.** If `w` solves the monic equation `w^d + Σ_{j<d} aⱼ wʲ = g`, then
`d · log⁺ ‖w‖ ≤ log⁺ ‖g‖ + d · Σ_{j<d} log⁺ ‖aⱼ‖ + d · log (2(d+1))`. The factor `d` in front of
`log⁺ ‖w‖` — as opposed to the Cauchy bound, which only gives `log⁺ ‖w‖ ≤ log⁺ ‖g‖ + …` — is the
whole point. -/
theorem nsmul_posLog_norm_le_of_monic_eq {d : ℕ} {a : ℕ → 𝕜} {w g : 𝕜}
    (h : w ^ d + ∑ j ∈ range d, a j * w ^ j = g) :
    d * log⁺ ‖w‖ ≤ log⁺ ‖g‖ + d * ∑ j ∈ range d, log⁺ ‖a j‖ + d * log (2 * (d + 1))

/-- **Unweighted root bound**, sharper constant, for `g = 0`. -/
theorem posLog_norm_le_of_monic_eq_zero {d : ℕ} {a : ℕ → 𝕜} {w : 𝕜}
    (h : w ^ d + ∑ j ∈ range d, a j * w ^ j = 0) :
    log⁺ ‖w‖ ≤ ∑ j ∈ range d, log⁺ ‖a j‖ + log d

/-- **Clunie, pointwise.** -/
theorem posLog_norm_le_of_pow_mul_eq {n p : ℕ} {a b : ℕ → 𝕜} {w : 𝕜}
    (h : w ^ n * (∑ j ∈ range (p + 1), a j * w ^ j) = ∑ k ∈ range (n + 1), b k * w ^ k) :
    log⁺ ‖∑ j ∈ range (p + 1), a j * w ^ j‖
      ≤ ∑ j ∈ range (p + 1), log⁺ ‖a j‖ + ∑ k ∈ range (n + 1), log⁺ ‖b k‖
        + log (max (p + 1) (n + 1))

/-- **Mohon'ko, pointwise.** Needs `a 0 ≠ 0` (at points where `a 0` vanishes, the right-hand
side degenerates to `log⁺ 0⁻¹ = 0` and the inequality is false). -/
theorem posLog_norm_inv_le_of_eq_zero {d : ℕ} {a : ℕ → 𝕜} {w : 𝕜}
    (h : ∑ j ∈ range (d + 1), a j * w ^ j = 0) (h₀ : a 0 ≠ 0) :
    log⁺ ‖w‖⁻¹ ≤ log⁺ ‖a 0‖⁻¹ + ∑ j ∈ Ico 1 (d + 1), log⁺ ‖a j‖ + log d
end Real
```

Proof sketches.

- *Weighted bound.* `d = 0` is trivial (`g = 1`). For `d ≥ 1` set `A := 1 + Σ_{j<d} ‖aⱼ‖ ≥ 1`.
  **Case `‖w‖ ≥ 2A`:** since `‖w‖ ≥ 1`, `‖w‖ʲ ≤ ‖w‖^{d−1}` for `j < d`, so
  `‖g‖ ≥ ‖w‖^d − (A − 1)‖w‖^{d−1} = ‖w‖^{d−1}(‖w‖ − A + 1) ≥ ‖w‖^d / 2`
  (as `‖w‖/2 ≥ A − 1`); hence `d · log ‖w‖ ≤ log ‖g‖ + log 2 ≤ log⁺ ‖g‖ + log 2`.
  **Case `‖w‖ < 2A`:** `d · log⁺ ‖w‖ ≤ d (log 2 + log A)` and
  `A ≤ (d + 1) · max 1 (max_j ‖aⱼ‖)` gives `log A ≤ log (d+1) + Σ_j log⁺ ‖aⱼ‖`. Both cases are
  below the common right-hand side.
- *Unweighted bound.* If `‖w‖ < 1` the left side is `0`. If `‖w‖ ≥ 1`, then
  `‖w‖^d ≤ Σ_j ‖aⱼ‖ ‖w‖ʲ ≤ (Σ_j ‖aⱼ‖) ‖w‖^{d−1}`, so `‖w‖ ≤ Σ_j ‖aⱼ‖` and `posLog_sum`
  (with `#(range d) = d`) finishes. (`d = 0` makes the hypothesis `1 = 0`.)
- *Clunie.* `‖w‖ ≤ 1`: `‖P(w)‖ ≤ Σ_j ‖aⱼ‖`, then `posLog_sum`. `‖w‖ > 1`:
  `‖P(w)‖ = ‖Q(w)‖ / ‖w‖ⁿ ≤ Σ_k ‖b_k‖ ‖w‖^{k−n} ≤ Σ_k ‖b_k‖`, then `posLog_sum`. Both bounds
  are below the sum of both right-hand sides with the larger `log`.
- *Mohon'ko.* `‖w‖ ≥ 1`: left side `0`. `‖w‖ < 1`: `w ≠ 0` (else `a 0 = 0`), and
  `a₀ = −w · Σ_{j≥1} aⱼ w^{j−1}` gives `‖a₀‖ ≤ ‖w‖ · Σ_{j≥1} ‖aⱼ‖`, so
  `‖w‖⁻¹ ≤ ‖a₀‖⁻¹ · Σ_{j≥1} ‖aⱼ‖`; `posLog_mul` and `posLog_sum` (with `#(Ico 1 (d+1)) = d`).

Sanity check: `w² − g = 0` (`d = 2`, `a = 0`): the weighted bound reads
`2 log⁺ ‖w‖ ≤ log⁺ ‖w²‖ + 2 log 6`, true with room to spare; the Cauchy bound would only give
`log⁺ ‖w‖ ≤ log⁺ ‖w²‖ + log 2`.

```lean
/-- B1. The order of a finite sum is at least the minimum of the orders. -/
theorem le_meromorphicOrderAt_sum {ι : Type*} {s : Finset ι} {f : ι → 𝕜 → E} {x : 𝕜}
    {n : WithTop ℤ} (hf : ∀ i ∈ s, MeromorphicAt (f i) x)

    n ≤ meromorphicOrderAt (∑ i ∈ s, f i) x
  -- Finset induction; `meromorphicOrderAt_add` for the step, `meromorphicOrderAt_const` (= ⊤
  -- for the zero function) for the base.

/-- B2. **Pole divisor under a monic relation**, weighted form: if
`f^d + Σ_{j<d} aⱼ fʲ = h` (as functions), then `d • (div f)⁻ ≤ (div h)⁻ + d • Σ_j (div aⱼ)⁻`. -/
theorem MeromorphicOn.nsmul_negPart_divisor_le_of_monic_eq {f : 𝕜 → 𝕜} {a : ℕ → 𝕜 → 𝕜}
    {d : ℕ} {U : Set 𝕜} (hf : MeromorphicOn f U) (ha : ∀ j, MeromorphicOn (a j) U) :
    d • (divisor f U)⁻
      ≤ (divisor (f ^ d + ∑ j ∈ range d, a j * f ^ j) U)⁻ + d • ∑ j ∈ range d, (divisor (a j) U)⁻
```

Proof of B2, pointwise at `z ∈ U` (outside `U` all sides vanish). If `meromorphicOrderAt f z`
is `⊤` or `≥ 0`, the left side is `0`. Otherwise `ord f = −k`, `k ≥ 1`, and the left side is
`d·k`. Write `h := f^d + Σ_j aⱼ fʲ`.
- **Case `ord h ≤ −d·k`:** then `(div h)⁻ z ≥ d·k`. Done.
- **Case `ord h > −d·k`:** from `f^d = h − Σ_j aⱼ fʲ` and B1,
  `−d·k = ord (f^d) ≥ min (ord h, min_j (ord aⱼ − j·k))` (`meromorphicOrderAt_pow`,
  `meromorphicOrderAt_mul`, `meromorphicOrderAt_neg`). The minimum is not attained by `ord h`,
  so some `j < d` has `ord aⱼ ≤ −(d − j)·k ≤ −k`, i.e. `(div aⱼ)⁻ z ≥ k`, and the right-hand
  side is `≥ d·k`.
All `WithTop ℤ` manipulations go through `WithTop.coe_le_coe`, `untop₀` and `omega` after
`lift`; `⊤`-valued coefficients (`aⱼ ≡ 0` near `z`) never attain the minimum and need no
special treatment beyond `le_top`.

Sanity check: `f = (·)⁻¹`, `d = 2`, `a = 0`: `h = (·)⁻²`, both sides are `2·δ₀`. With
`a₁ = −(·)⁻¹`: `h = (·)⁻² − (·)⁻² = 0`, `(div h)⁻ = 0`, and the right side `0 + 2·(1·δ₀) = 2δ₀`
still dominates `2δ₀` — the coefficient absorbs the cancellation, as it must.

```lean

theorem MeromorphicOn.nsmul_negPart_divisor_add_posPart_divisor_le {f : 𝕜 → 𝕜}
    {a b u v : ℕ → 𝕜 → 𝕜} {p q : ℕ} (hqp : q ≤ p) … (hBezout : (∑ U-coeffs) * P(f) + (∑ V-coeffs) * Q(f) = 1) :
```

### F3 = T6. Relative algebraic closedness

Given `ha : IsAlgebraic (growthField hG) a`:
1. `isAlgebraic_iff_isIntegral` (base is a field) ⟹ monic `p : (growthField hG)[X]` with
   `aeval a p = 0`.
2. `Polynomial.Monic.as_sum`: `p = X ^ n + Σ_{i<n} C (p.coeff i) * X ^ i`, `n := natDegree`;

3. Representatives: `out a`, `out (p.coeff i)`; `Subtype.ext_iff` + `Germ.coe_eq` turn step 2

5. Each `characteristic (p.coeff i) ∈ G` (membership in the growth field), so the right side is
   in `G` (`add`, `const`), and `of_le` (with `characteristic_nonneg`, eventually `1 ≤ r` from

## 9. Work package G — the sharp rational identity (T8, T9)

*New file `VD/AlgebraicDependence/RationalCharacteristic.lean`. Depends on A (Bezout

Notation: `F := growthField hG`, `K := germRing ℂ univ`, `P, Q : F[X]`, `p := P.natDegree`,
`q := Q.natDegree`, `g := aeval a P / aeval a Q`, "`≤ₛ`" means "`≤` up to an additive function in
`G`, eventually along `l`".

### G1. Upper bound: `T(g) ≤ₛ max p q · T(a)`

Induction on `q` (strong induction `Nat.strong_induction_on`), statement quantified over all
`P` and all `Q` with `Q.natDegree = q`, `Q ≠ 0`:
- `q = 0`: `Q = C c`, `c ≠ 0`; `T(aeval a P / c) ≤ₛ T(aeval a P) ≤ₛ p·T(a)` (F5 upper half,
  `characteristic_algebraMap`, `characteristic_mul_le`).
- `q ≥ 1`, `p ≥ q`: `P = S * Q + P₁` with `S := P / Q`, `P₁ := P % Q`
  (`EuclideanDomain.div_add_mod`), `P₁.degree < Q.degree` (`degree_mod_lt`),
  `S.natDegree = p − q`. Then `g = aeval a S + aeval a P₁ / aeval a Q`, so
  `T(g) ≤ₛ T(aeval a S) + T(aeval a P₁ / aeval a Q) ≤ₛ (p−q)·T(a) + T(aeval a Q / aeval a P₁)`
  (F5, `exists_abs_characteristic_inv_sub_le`; if `P₁ = 0` the second term is `T(0) = 0`), and
  the induction hypothesis with denominator `P₁` (`P₁.natDegree < q`) gives
  `T(aeval a Q / aeval a P₁) ≤ₛ max q P₁.natDegree · T(a) = q·T(a)`. Total `p·T(a)`.
- `q ≥ 1`, `p < q`: `T(g) = T(1/g) + O(1)` and `1/g = aeval a Q / aeval a P` has denominator
  degree `p < q`: induction hypothesis gives `max q p · T(a) = q·T(a)`.
Coprimality is **not** needed for the upper bound.

### G2. Pointwise Bezout estimate (goes to package A)

```lean
theorem Real.nsmul_posLog_norm_add_posLog_norm_inv_le {p q : ℕ} (hqp : q ≤ p)
    {a b u v : ℕ → 𝕜} {w : 𝕜} (hp : a p ≠ 0) (hq : b q ≠ 0)
    (hB : (∑ i ∈ range q, u i * w ^ i) * (∑ j ∈ range (p+1), a j * w ^ j)
        + (∑ i ∈ range p, v i * w ^ i) * (∑ k ∈ range (q+1), b k * w ^ k) = 1) :
    (p - q) * log⁺ ‖w‖ + log⁺ ‖∑ k ∈ range (q+1), b k * w ^ k‖⁻¹
      ≤ log⁺ ‖(∑ j, a j * w ^ j) / (∑ k, b k * w ^ k)‖
        + (small: an explicit linear combination of log⁺ ‖a j‖, log⁺ ‖a p‖⁻¹, log⁺ ‖b k‖,
           log⁺ ‖b q‖⁻¹, log⁺ ‖u i‖, log⁺ ‖v i‖, and absolute constants depending on p, q)
```

Proof: `R₀ := 2 (1 + Σ ‖aⱼ‖/‖a_p‖)` (so that `‖P(w)‖ ≥ ‖a_p‖‖w‖^p / 2` for `‖w‖ ≥ R₀`, as in
A). **Region `‖w‖ ≥ max 1 R₀`:** `‖Q(w)‖ ≤ (Σ‖b_k‖)‖w‖^q`, so
`log⁺ ‖P/Q‖ ≥ (p−q) log ‖w‖ − log⁺ ‖a_p‖⁻¹ − log⁺ (Σ‖b_k‖) − log 2`; and
`‖Q(w)‖ ≥ ‖b_q‖‖w‖^q/2 ≥ ‖b_q‖/2` gives `log⁺ ‖Q(w)‖⁻¹ ≤ log 2 + log⁺ ‖b_q‖⁻¹` — small.
**Region `‖w‖ < max 1 R₀`:** `(p−q) log⁺ ‖w‖ ≤ (p−q) log⁺ R₀` — small. If `‖Q(w)‖ ≥ 1` the
second left term is `0` and `log⁺ ‖P/Q‖ ≥ 0`. Else, with `‖U(w)‖, ‖V(w)‖ ≤ Σ‖uᵢ‖ R₀ⁱ`-type
bounds (small): if `‖Q(w)‖ ≥ 1/(2 max 1 ‖V(w)‖)` then `log⁺ ‖Q(w)‖⁻¹ ≤ log 2 + log⁺ ‖V(w)‖`
— small; otherwise `‖V(w) Q(w)‖ ≤ 1/2`, so `‖U(w) P(w)‖ ≥ 1/2`, `‖P(w)‖ ≥ 1/(2‖U(w)‖)`, and
`log⁺ ‖P/Q‖ ≥ log⁺ ‖Q(w)‖⁻¹ − log 2 − log⁺ ‖U(w)‖`. In every branch the left side is at most
the right side plus small terms. (Mohon'ko's argument; Laine's proof of Theorem 2.2.5 is this
estimate plus the counting-function analogue B3.)

### G3. Lower bound: `max p q · T(a) ≤ₛ T(g)` for coprime `P, Q`

WLOG `q ≤ p` (else invert: `T(g) = T(1/g) + O(1)`, `IsCoprime.symm`). Get `U, V` from
`hPQ : IsCoprime P Q` (`∃ U V, U * P + V * Q = 1`); their coefficients lie in `F`, so all

through `logCounting_le`:
`(p−q)·T(a) + T(1/aeval a Q) ≤ₛ T(g)`. By FMT inversion and F5,
`T(1/aeval a Q) ≥ₛ T(aeval a Q) ≥ₛ q·T(a)`. Hence `p·T(a) ≤ₛ T(g)`.

## 12. Risks and fallbacks

1. **The factor `d` (A1, B2).** The weighted pointwise bound is the one non-obvious inequality
   on the function level; the case split `‖w‖ ≥ 2A` is exactly where it is won. Verified by
   hand above (and the sanity check `w² = g`). Fallback: none needed — if the constant turns out
   wrong, only the additive constant changes, never the factor.
2. **`Pi`-expressions vs. pointwise evaluation.** `(f ^ d + ∑ j ∈ range d, a j * f ^ j) z`
   must `simp` to `f z ^ d + ∑ j ∈ range d, a j z * f z ^ j` (`Finset.sum_apply`,
   `Pi.add_apply`, `Pi.mul_apply`, `Pi.pow_apply`). Meromorphy of the expression: `Meromorphic.add`,
   `.pow`, `.mul`, `Meromorphic.sum`-type lemmas; if the `Finset.sum` version is missing, prove a
   two-line `meromorphic_sum` helper (Finset induction). Fallback: state everything with
   `fun z ↦ …` instead of `Pi` operations.
3. **Degenerate coefficients.** `aⱼ ≡ 0`, `f ≡ 0`, `g ≡ 0` are all covered: A needs no
   nonvanishing, B2 handles `⊤` orders by `le_top`, C0 removes the `≠ ⊤` hypotheses. Only D2
   needs `a_d ≢ 0` (division), and T3 is false without it (`a_d ≡ 0` lowers the degree).
4. **Integration on codiscrete sets (E, G3).** `circleAverage_mono_codiscreteWithin` needs the
   inequality `=ᶠ[codiscreteWithin (sphere 0 |r|)]`; converting from `codiscrete ℂ` is
   `Filter.codiscreteWithin.mono`-style plumbing already done in the LLD files — copy the device.
5. **`IntermediateField` for the growth field.** `inv_mem'` needs the FMT inversion constant,
   which is a *function of `a`* (`c_a`); the growth class absorbs it (`const`). `neg_mem'`:
   `−a = (−1) • a`, use `characteristic_mul_le` with `characteristic_algebraMap`. If
   `IntermediateField` causes friction with the `Algebra ℂ K` instance from
   `VD/Field/GermFieldAPI.lean` (it is `(constRingHom ℂ univ).toAlgebra`), fall back to
   `Subfield K` and state T6 with `Algebra`-free `IsAlgebraic` via `Subfield.toIntermediateField`.
6. **Little-o growth class for constant `f`.** `characteristic f ⊤` bounded ⟹ `(· =o φ)` is
   not a growth class (constants are not `o(1)`). Handled by taking `Tendsto φ l atTop` as a
   hypothesis of `isGrowthClass_isLittleO`; `smallFunctions f` is only defined for nonconstant
   `f` (hypothesis argument). This matches the classical convention that `S(r, f)` is only used
   for nonconstant `f`.
7. **G is where the plan may need revision.** G2's branch structure and B3's case analysis are
   long; both are elementary and purely local. If G3 stalls, T8 remains available as a one-sided
   statement (G1 upper bound, coprimality-free) plus the lower bound
   `T(r, f) ≤ T(r, g) + S` from (AD) — enough for many applications (e.g. "if `g = R(f)` is
   small then `f` is small"). Document that fallback in the file if used.
8. **Naming.** `nsmul_characteristic_le_of_monic_eq`, `growthField`, `IsGrowthClass`,
   `smallFunctions` are placeholders; expect review bikeshedding. Nothing downstream depends on
   them.
